Source

Freshness

How it's computed
"Last full month" is the most recent complete calendar month — the in-progress month is deliberately excluded so partial data never flatters the trend. Month-over-month, year-over-year, and the 12-month average are all computed on complete months only.

Goal 2 · Hold the rankings you already won

Priority keyword positions Live

Source
Three rank sources are shown side by side so they can be cross-checked: Semrush (US) current, Ubersuggest (US) current, and the Google Search Console 90-day average. The sample is 40 priority keywords, every one ranking right now, benchmarked from June 15, 2026.
Freshness
The headline "holding" position is the live current rank (Semrush, or Ubersuggest where Semrush has no entry); the Search Console 90-day average is shown alongside for comparison. Last checked: —.
How it's computed
"Holding page 1" = keywords at position ≤ 10; "in top 5" = ≤ 5. The pass line is 35 of the 40 keywords.
Honest caveats
The 40-keyword list is a curated working sample of keywords that actually rank right now — anything not ranking was removed. The three sources can differ (Semrush and Ubersuggest are point-in-time; Search Console is a 90-day average), which is exactly why all three are shown.

Goal 4 · Compete with the other big Israeli charities

Share of organic traffic

Source
Semrush organic-traffic estimates for RMBH and the competitor set. Headline view (leading Israel charities): Colel Chabad, Meir Panim, Lev LaLev, Yad Ezra, Yad Eliezer, Latet. Second view (direct Rabbi-Meir charities): Kupath Rabbi Meir, Rabbi Meir Baal Haneis, Reb Meir.
Freshness
This is the one metric that is NOT auto-live: competitors' traffic isn't available from Google's APIs — only from Semrush — so it refreshes on a manual Semrush pull, not automatically. Pulled: —.
How it's computed
Each domain's share = its estimated organic traffic ÷ the total of the tracked set; rank is by traffic.
Honest caveats
Semrush estimates differ from GSC actuals (different methodology — that's why RMBH's Semrush traffic estimate and its GSC clicks aren't the same number). Yad Eliezer and Latet don't register in Semrush's US database (their traffic is Israel-based) and are shown as "no data," not zero. To make this metric live would require Semrush API units.
Goal 5 · Be the AI-named entity

AI recognition Live

Source
Live API calls each scan to ChatGPT (gpt-4o), Gemini (2.5-flash), and Google AI Search (Gemini + Google's search-grounding). Claude and Perplexity are pending API credit and switch on automatically once funded.
Freshness
Live, re-queried each refresh; the actual answers are archived with their date. Last scan: —.
How it's computed
A "mention" counts only when the answer names the client organisation — "Rabbi Meir Baal Haness Charities" or rmbhcharities.com. It deliberately does NOT count the generic sage's name, the abbreviation "RMBH" (which also means Ronald McDonald House), or the competitor "Kupath Rabbi Meir Baal Haness."
Honest caveats
AI answers are non-deterministic, so the count varies scan to scan — that's normal, not a data error. The matrix shows only the engines that actually ran, and you can expand any prompt to read the real answer that named RMBH.

How accuracy is enforced

Self-checking, every week

Guardian
Before anything is published, an automated Accuracy Guardian re-derives every figure independently from the source data and blocks the deploy if any number is off — it even fault-tests itself by injecting a deliberate error to prove it catches one.
Live monitor
A daily check confirms the live site stays up, fresh, and correct, and flags any drift.
No fabrication
Every keyword and figure carries a labelled source; nothing is placeholder or invented. Where a number is an estimate (Semrush search volumes, competitor traffic) it is labelled as an estimate, and rankings/impressions/donations are measured from live Google data.
Refresh cadence
The live goals refresh weekly via a scheduled task on the agency's machine (it last ran successfully and is verified). If that machine is off at the scheduled time the run is deferred to the next opportunity, and the data-freshness dates above always show the true last-update time — the dashboard never claims fresher data than it has.
