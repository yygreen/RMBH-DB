# RMBH Growth Dashboard

Live client dashboard for the Rabbi Meir Baal Haness Charities (rmbhcharities.com) organic-growth
engagement, built and maintained by Rank Friendly.

**Live URL:** https://rmbh-dashboard.josephgreen.ai/

## What it is

A static multi-page site fed by JSON data files that are refreshed from Google Search Console +
Google Analytics 4 and redeployed. North-star goal: **+5% organic traffic month over month**,
tracked across five strategic goals (Preserve / Enhance / Broaden / Establish / Ensure) plus a
"500 Deliverables" program tracker and a client proposal page.


## Deploying

```
cd site
npx vercel --prod --yes --token $VERCEL_RMBH_TOKEN --scope rmbh
npx vercel alias set <deployment-url> rmbh-dashboard.josephgreen.ai --token $VERCEL_RMBH_TOKEN --scope rmbh
```

## KNOWN GAPS — read before deploying

1. **`/api/edits` serverless function is NOT in this repo.** The deployed site has a Node
   function (GET returns the edit-overlay JSON; POST with header `x-rmbh-key` and body
   `{ops: [...]}` persists comments/removals/added rows — see `edits-ui.js`). Its source could
   not be recovered over HTTP. Deploying `site/` as-is will 404 that endpoint and the edit
   overlay will silently fall back to read-only. Current overlay content is snapshotted in
   `docs/edits-overlay-snapshot-2026-08-18.json`.
2. **The data refresh rail is not in this repo.** The weekly GSC/GA4 pull that regenerates the
   `*.json` files runs on the office PC (pattern: PowerShell scheduled task + `npx vercel`
   deploy, same as the other josephgreen.ai dashboards). Recover it from the PC.
3. **Deploy-target divergence (active incident as of 2026-08-18).** The refresh rail deploys to
   Vercel project `rmbh-dashboard`, but the live domain is attached to project
   `rmbh-dashboard-live`, whose last deploy is Jul 29. Result: the live site shows Jul 29 data
   with a red STALE warning (its own threshold is 8 days), while Aug 4 data sits unpublished on
   the other project — and nothing at all refreshed after Aug 4, so the rail itself has also
   stopped. See `docs/PROJECT-CONTEXT.md` for the full picture.
